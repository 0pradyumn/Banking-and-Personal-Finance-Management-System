# Banking and Personal Finance Management System

A web-based frontend application designed to help users organize and manage their personal financial information through a simple and user-friendly interface.

## Features

- User Login / Registration UI
- Dashboard
- Account Management
- Income and Expense Tracking
- Transaction Categorization
- Budget Management
- Savings Goals
- Financial Reports and Summaries
- Account Balance Display
- Responsive User Interface
- Form Validation
- Dynamic UI Updates

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Git Workflow

The project follows:

```text
feature/*
     ↓
    dev
     ↓
    main
```

Each team member works on a separate feature branch. Completed features are merged into `dev` after review and testing. The stable version is eventually merged into `main`.
